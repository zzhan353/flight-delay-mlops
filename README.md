# Flight Delay MLOps

Predicting US domestic flight arrival delays, with the operational machinery that
makes a model trustworthy: reproducible data versions, a leakage guard enforced in CI,
an evaluation gate that blocks regressions, drift monitoring on genuinely new data,
and a live endpoint that costs under $1/month to run.

Full documentation is written up at the end of the build. See `Makefile` for entry points.
